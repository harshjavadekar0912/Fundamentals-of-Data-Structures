C DSA Algorithms Employed

  • 🛣️
    Dijkstra Shortest Path

    Min-Heap priority queue computes optimal routes in O((V + E) log V). Gracefully detects unreachable destinations.

  • 🔄
    Traveling Salesperson Problem (TSP)

    Recursion & backtracking with branch-and-bound pruning for global optimum, compared alongside Greedy Nearest Neighbor O(N²).

  • ⏳
    Opening Hours Constraint Scheduler

    Simulates visit durations, opening/closing gates, and enforces balanced daily 9-hour active bounds.

  • 🏨
    Min-Heap Hotel Optimizer

    Priority queue extracts cheapest stays in O(K log N), paired with in-place QuickSort for rating & distance.

  • 🌲
    AVL Self-Balancing Tree

    Stores trips with 4 rotation cases (LL, RR, LR, RL) for guaranteed O(log N) search, update, and sorted display.

DSA Technical Reference

Data Structures & Algorithmic Complexity

Complete theoretical and empirical specifications implemented in the C core backend.

01

Graph & Min-Heap (Dijkstra)

Adjacency list graph with Min-Heap priority queue for shortest travel distance and duration calculation.

Time Complexity: O((V + E) log V)
Space Complexity: O(V + E)
File: backend/location_route.c
02

TSP: Greedy vs Backtracking

Greedy nearest-neighbor approximation compared against exact branch-and-bound recursion for optimal attraction sequence.

Greedy Time: O(N²)
Exact Time: O(N!) pruned
File: backend/itinerary.c
03

Min-Heap & QuickSort

Priority queue extracting lowest accommodation prices with in-place QuickSort partitioning by rating, price, and distance.

Heap Extract: O(K log N)
Sort Time: O(N log N)
File: backend/budget.c
04

Hash Table with Chaining

Separate chaining hash table utilizing the djb2 polynomial rolling hash algorithm for rapid keyword and category searches.

Average Search: O(1)
Table Size: 127 (Prime)
File: backend/search.c
05

AVL Self-Balancing Tree

Self-balancing BST maintaining height balance factor within [-1, +1] using 4 rotation types (LL, RR, LR, RL) for persistent trips.

Search / Insert: O(log N)
In-Order Traversal: O(N)
File: backend/trip_management.c
